# SauceDemo Manual Testing Project

## About
This project contains manual testing artifacts for the SauceDemo web application.

The goal of this project is to demonstrate basic QA skills:
- test design
- bug reporting
- understanding of testing process

---

## Scope
The following functionality was tested:
- Login
- Product catalog
- Cart
- Checkout process

---

## Testing Types
- Functional testing
- UI testing
- Negative testing

---

## Project Structure
- `test_plan.md` – test strategy and scope
- `test_cases.md` – detailed test cases
- `bug_reports.md` – identified issues and improvements
- `screenshots/` – evidence of test execution

---

## Tools
- Browser: Chrome
- Documentation: Markdown
- Version Control: Git
